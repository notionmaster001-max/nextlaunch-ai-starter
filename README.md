## 🛠️ Quick Start

```bash
# Clone the repository
git clone https://github.com/notionmaster001-max/nextlaunch-ai-starter.git
cd nextlaunch-ai-starter

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
